# MHXX スキルシミュレーター (Save Data Charm Direct Reader)

**Web 版（GitHub Pages — インストール不要・ブラウザで今すぐ使えます）:**  
https://nexy451z.github.io/mhxx-skill-simulator/

Nintendo Switch / ニンテンドー3DS『モンスターハンターダブルクロス（MHXX）』および『Monster Hunter Generations Ultimate（MHGU）』の `system` セーブファイルから所持している護石（お守り）をブラウザ上で直接抽出・インポートしてスキルシミュレートができる、スタンドアロン Web スキルシミュレーターです。

サーバーへのファイル送信は一切行わず、すべてブラウザ内（ローカル JavaScript / Web Worker）で完結します。`index.html` を直接ブラウザで開くだけで動作します。

---

## 主な特徴

### 1. セーブデータ（`system`）お守り直読み機能
- JKSV 等でバックアップした Switch 版 `system`（`4,726,188` bytes）または 3DS 版 `system`（`4,726,152` bytes）をドラッグ＆ドロップ（またはファイル選択）するだけで、セーブスロット 1〜3 の装備 BOX（各 2,000 枠）から護石だけを自動判別・抽出します。
- スロットごとの個別インポート・全スロット統合インポートに対応し、**「追加（重複スキップ）」**と**「上書き置換（既存クリア）」**を選択できます。
- 抽出したお守りはブラウザの `localStorage` に自動保存され、次回起動時もそのまま利用できます。

### 2. お守り管理（手動登録・編集・削除・テキスト入出力）
- **手動登録・編集・削除**: 護石の種類（兵士の護石〜天の護石）、第1・第2スキル系統とポイント（マイナスポイント対応）、スロット数（0〜3）を指定して追加・編集・個別削除・全削除が可能です。
- **テキスト入出力**: 既存のスキルシミュレーター（泣シミュ等）互換のカンマ区切り形式（`スキル1,値1,スキル2,値2,スロット数`）やラベル形式での一括インポート・エクスポートに対応しています。
- **検索モード切替**: 「手持ちのお守りをすべて対象にする（全検索）」と「特定の 1 個のお守りを固定して検索」をワンクリックで切り替え可能です。お守りを追加・取込・削除すると検索条件へ即時反映されます。
- **理論値お守り逆引きモード（トグル）**: STEP 2 のトグルを ON にすると、**未所持・未登録でも** MHXX の護石仕様（護石の種類ごとの上限・スロット数・第1/第2スキル上限）に沿った「理論値お守り」を仮定し、現在の条件に**追加で発動できるスキル**を右ペインに列挙します。候補スキルごとに「そのお守り＋装備で条件を満たせるか」を検索し、見つかれば `例: 女王の護石 聴覚保護+1 攻撃+10 スロ3（防御 860）` のように根拠のお守りと防御力を表示。ワンクリックで「条件に追加」または「このお守りを登録」ができます。計算は候補ごとに分割実行し、進捗バー・キャンセル・再計算・結果キャッシュに対応しています。

### 3. MHXX 仕様完全準拠の高速検索エンジン
- **全マスタデータ収録**: 防具 **6,025 件**（頭 1,241 / 胴 1,226 / 腕 1,195 / 腰 1,149 / 脚 1,214）、装飾品 **242 件**、発動スキル **324 件**（スキル系統 **206 種**）。
- **胴系統倍加**: 胴系統倍加を持つ部位数に応じて、胴防具の素スキルポイントおよび**胴スロットに装着した装飾品のスキルポイント**を `1 + 倍加部位数` 倍として正確に計算します。
- **ネセト一式（スキル加点+2 ／ 護石系統倍加）**: 秘術（スキル加点+2）と護石系統倍加（護石素スキル×2 ＋ 護石スロット装飾品×2）の組み合わせを自動探索します。
- **3穴プール型装飾品ソルバ**: MHXX のスロット仕様（3スロ防具＝容量3の穴プールであり、【3】珠×1・【2】珠+【1】珠・【1】珠×3 のいずれも装着可能）を厳密に再現し、装飾品のマイナススキルによる必須スキル割れも自動補填します。
- **下位互換お守り事前枝刈り ＆ 非同期検索**: 数百個の護石をインポートした状態でも、必須スキル系統とスロット数から下位互換の護石・防具を事前に枝刈り（パレートフィルタリング）し、UI スレッドを止めずに高速検索します。

### 4. 直感的な 2 ペイン UI ＆ スキルポイント内訳マトリクス
- **STEP 1〜3 コントローラー**: 剣士/ガンナー切替、武器スロット（0〜3）ワンタップ切替、性別（男性/女性）切替、8 カテゴリタブ、**スキル名＋スキル系統名**（例：「達人」「痛撃」「聴覚保護」）での横断インクリメンタルサーチ、同系統スキルの自動排他選択。
- **さらに追加できるスキル提案**: 現在の検索結果の空きスロット形状・余剰ポイントから、既存の必須スキルを壊さずに追加発動できるスキル候補を自動算出し、ワンクリックで検索条件に追加できます。
- **スキルポイント内訳マトリクス表**: 部位別（武器・頭・胴・腕・腰・脚・護石）の装備名、同性能の代替防具候補（「他N件」展開表示）、装着装飾品バッジ、各スキル系統のポイント内訳、合計値と発動スキル、初期防御力・5属性耐性を一覧表示します。

## 使い方

1. リポジトリをクローンまたは Releases から ZIP をダウンロードして展開します。
2. `index.html` を Web ブラウザ（Chrome / Edge / Firefox / Safari 等）で開きます（ローカルの `file://` 直開きでそのまま動作します）。
3. **STEP 1** で「剣士 / ガンナー」「武器スロット 0〜3」「男性 / 女性」を選択します。
4. **STEP 2** で `system` セーブファイルをドロップしてお守りをインポートするか、「新規登録 / 管理」からお守りを登録します。
5. **STEP 3** で発動させたいスキルをタップして ON にすると、右ペインに検索結果とスキルポイント内訳マトリクスがリアルタイムに表示されます。

## 免責事項

- 本ツールは非公式のファンメイドツールです。ゲームの生データファイル（`romfs` バイナリ等）やセーブデータは一切同梱していません。
- セーブデータの読み込みはブラウザ上のメモリ（`ArrayBuffer`）に対する読み取り専用処理であり、元のセーブファイルを書き換えることはありません。
